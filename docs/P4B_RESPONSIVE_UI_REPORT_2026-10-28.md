# RoBattles! P4-B — 반응형 UI / 작은 화면 최적화 구현 보고서

- 기준 소스: P4 UI 커밋 `5f3c7c5` (`p4/ui-polish`), 이전 QA4 → P1 → P2 → P3 누적 기준 유지
- 작업 범위: **클라이언트 UI 표시 레이아웃만 수정**. 서버·전투·캐릭터·애니메이션·입력 규칙 변경 없음.
- 구현 상태: **코드 수정 완료, 정적·Python 오프라인 검사 통과, Luau 컴파일 및 Roblox Studio 실기 검증 미실행**

## 1. 변경 내용

| 화면 | 변경 내용 |
|---|---|
| 전체 | `UI/Responsive.luau`로 데스크톱(1280×720), 작은 가로(1024×576), 세로(720×1180) 기준 캔버스 선택. 각 화면 크기에 맞게 축소 비율 계산 |
| 안전 영역 | `ScreenGui`가 제공하는 inset을 사용하도록 전환, 지원 환경에서는 DeviceSafeInsets 지정 |
| 메뉴 | 작은 가로·세로 화면에서 버튼·타이틀·미리보기·설명 위치를 재배치 |
| 캐릭터 선택 | 세로 화면에서는 캐릭터 카드 2열, 미리보기·스킬 정보를 수직 배치. 기술 설명은 스크롤 유지 |
| HUD | HP·스킬 5칸·궁극기·명중/KO·상단 경기 정보를 별도 레이아웃으로 재배치 |
| 설정/스코어보드 | 세로 화면에서 설정 버튼·스크롤 영역·순위 행 크기 및 위치 재조정 |
| 화면 회전 | 해상도 프로필 전환 시 생성 당시 기본 좌표를 복원한 다음 새 레이아웃을 적용. UI 상태나 서버 데이터를 초기화하지 않음 |

## 2. 변경 파일

- `src/client/UI/Responsive.luau` — 신규 레이아웃 프로필
- `src/client/UI/App.luau` — 해상도 대응, 안전 영역 및 메뉴/선택 화면
- `src/client/HudView.luau` — 전투 HUD 위치 조정
- `src/client/ScoreboardView.luau` — 결과·스코어보드 화면 조정
- `src/client/SettingsView.luau` — 설정 목록과 키 설정 항목 크기 조정
- `tests_py/test_p4b_responsive_contract.py` — P4-B 소스 계약 테스트

## 3. 검증 결과

- 신규 P4-B 5개 테스트 및 P4/P3·전투 현재 시뮬레이션 테스트: **49 passed, 3 deselected** (과거 변경 허용 목록 검사 3개 제외)
- `tools/preflight_offline.py` 기반 오프라인 Python 소스 사전검사: **PASS**, 현재 전투 27개 통과, 기존 Phase1 레거시 시뮬레이션 4개 실패는 신규 실패가 아님
- Rojo JSON/마운트, Remote 및 리터럴 require 경로 정적 확인: **PASS**
- 전체 구형 `pytest tests_py tests_sim_current`: 이전 단계 파일 동일성 및 변경 허용 범위 검사 **7개 실패**. P4 변경 전부터 누적된 구형 테스트 계약과의 충돌이며 P4-B 시각·입력 정상 동작을 보증하지 않음.
- **Luau 실행/컴파일/분석과 Roblox Studio 렌더링·실제 입력·화면 회전·FPS 검증: 미실행**

## 4. 범위 밖 / 후속 필수

- 휴대폰 터치 전투 조작 버튼 또는 터치 입력 구현은 이번 범위에 **포함하지 않음**. 작은 화면에서 UI 배치만 적응함.
- 가상 키보드, 플랫폼마다 다른 안전 영역, TV 콘솔 및 화면 비율 극단값은 실기 검증 필요.
- 기기별 글자 잘림, 메뉴 버튼 터치 영역, 전투 중 UI 가림, 경기 종료·죽음 화면, 화면 회전 및 재접속을 실제 Studio/Roblox 플레이 테스트에서 검증할 것.
- GitHub 업로드 또는 정식 배포 없음. 결과물은 독립된 로컬 Git 브랜치와 ZIP/패치임.
