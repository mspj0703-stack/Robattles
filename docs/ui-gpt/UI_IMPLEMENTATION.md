# RoBattles! Alpha 1.0 UI — 구현 및 인계

작성: 2026-10-25 (한국 시간)
판정: **접근 가능한 소스에 UI 구현 완료. 실제 Phase 2 브랜치 병합·Studio 검증·서버 확장 연동은 미완료.**

## 기준 소스 및 작업 트리

- 기준: `RoBattles_Phase2_Sword_Step1a.zip` (검색 당시 접근 가능한 최신 Phase 2 소스).
- ZIP SHA-256: `e07caacee24dc045d592d4bf3d7a934bcab190fcbb4a391c774827be70723b5f`
- 로컬 작업 공간에 기존 Git 저장소가 없었으며 ZIP에도 `.git` 및 `AGENTS.md`가 없었다.
- 따라서 Claude 실제 작업 트리의 미커밋 변경, 원격 최신 커밋, 공통 기준 커밋은 확인 불가.
- **`phase2/ui` 브랜치를 임의 생성하지 않았다.** 해당 이름은 병합 목표 브랜치다. 임의 초기 커밋을 공통 기준으로 가장하지 않았다.
- 원본 압축 파일을 보존하고 별도 소스 사본을 수정했다. 전투·공유 계약·맵·시뮬레이션 소스는 원본과 바이트 비교한다.
- 전체 소스와 함께 UI 변경만 담은 `ui.patch`, 원본 파일 해시 목록을 제공한다. Claude 최신 소스에 전체 폴더를 덮어쓰지 말 것.

## 모듈 구조

- `Main.client.luau`: 기존 입력·Remote 구독의 소유자 유지. UI 이벤트 전달과 메뉴 입력 차단만 연결.
- `UI/App.luau`: 단일 ScreenGui, 메뉴/캐릭터/도움말/사망/결과 화면, 서버 데이터 전달, 설정 적용.
- `UI/State.luau`: 순수 표시 상태. 스냅샷 시각·사망/부활 수명·선택 요청·피드·응답 지연 처리.
- `UI/Components.luau`: Frame/Text/Button/Bar/Scroll 생성. UIStroke/UICorner/UIScale와 0.09초 트윈.
- `UI/Tokens.luau`: 지정된 공통 색상, 캐릭터 테마, 글꼴, 교체할 이미지 ID.
- `UI/Catalog.luau`: 화면용 설명만 보유. 피해/쿨타임 규칙을 정의하지 않음.
- `UI/Preview.luau`: 서버 모델이나 전투 카메라를 건드리지 않는 ViewportFrame 임시 장면.
- `HudView`, `ScoreboardView`, `SettingsView`: 기존 파일을 교체. 별도 ScreenGui/전역 입력 구독을 만들지 않음.

기본 캔버스 1280×720. 실제 화면의 여유 폭·높이와 사용자 설정 중 작은 배율로 맞춘다. 설정·캐릭터 상세는 스크롤된다. 작은 창에서 화면 밖으로 나가지 않는 수학적 배율 테스트를 수행했지만 실제 글자 가독성/클리핑은 Studio 검증이 필요하다.

UI 인스턴스는 초기 생성 후 재사용한다. HUD 렌더는 최대 20Hz, 카메라·기존 이동 루프는 그대로 매 프레임 동작한다. 스코어보드는 12개 행을 재사용하며, 모의 테스트에서 100회 렌더 중 새 GUI 객체 생성 0건을 확인했다.

## 화면과 입력 수명

- F9: 메인 메뉴 토글. F10: 설정. Tab은 기존 InputState 경로 하나만 사용.
- 메뉴/설정/도움말/선택/사망/결과/연결 대기 시 전투 입력을 차단하고 눌린 키·Tab 상태를 해제한다.
- 모달 진입 시 실행 중 달리기를 기존 SetRun(false) 요청으로 해제한다. 이동 판정·검증 코드는 수정하지 않는다.
- 메뉴 중 카메라 회전 입력을 받지 않고 마우스 잠금을 해제한다. 기존 카메라 설정은 유지해 복귀한다.
- 캐릭터 제거/추가 시 이전 HUD 스냅샷과 일시적 피드백을 지우고 다음 서버 스냅샷을 기다린다.
- 선택 요청은 하나만 진행하며 5초 후 응답 지연으로 표시한다. 서버 스냅샷의 pendingCharacterId/characterId로만 확인한다.
- 3초 이상 새 State를 받지 못하면 지연 안내와 입력 차단. 새 유효 스냅샷 수신 시 복구.
- 서버가 실제로 종료를 알리지 않으므로 타이머를 임의로 만들어 결과 화면을 띄우지 않는다.

## 아트와 음원 교체

`UI/Tokens.luau`의 `Assets.Logo`, `Assets.Portraits.SWORD` 등에 Roblox 이미지 ID를 입력한다. 스킬 아이콘 키는 `Assets.Skills["SWORD/Primary"]` 형식이다. 없는 이미지는 기존 텍스트/블록 미리보기로 표시한다.

기본 EffectPlayer가 생성하는 효과음은 `SoundService.RoBattlesSFX` 그룹에 연결했다. 향후 음악은 `RoBattlesMusic` 그룹에 연결해야 음악 설정이 적용된다. 대체 VFX 모델에 자체 Sound가 있다면 해당 그룹을 지정해야 한다. 권한 있는 최종 음원/이미지 업로드는 별도 작업이다.

## 검증과 잔여 범위

정확한 실행 결과는 `UI_TEST_RESULTS.md`, 서버 계약은 `UI_DATA_CONTRACT.md`, 수동 검증은 `UI_STUDIO_CHECKLIST.md`를 참고한다. Roblox Studio 및 실제 Rojo 빌드는 실행하지 않았다. CLI 통과는 실제 멀티플레이·엔진 렌더링 통과를 의미하지 않는다.
