# Studio P0 — 모두 NOT RUN

준비: 실제 최신 전투 checkpoint와 병합한 별도 place에서 `integrated.project.json` 사용. 2클라이언트부터 시작하고 최종 12클라이언트로 검증한다. 단일 클라이언트 화면만 확인하고 완료 처리하지 않는다.

## P0-1 최초 입장/선택

- [ ] 처음 접속한 Menu 사용자는 캐릭터가 자동 생성되지 않으며 경기 준비 인원에도 포함되지 않는다.
- [ ] 첫 SelectCharacter는 모델이 없어도 스키마/rate limit을 거쳐 처리된다.
- [ ] 첫 선택 캐릭터로 스폰한다. 두 번째 선택·연속 클릭이 중복 LoadCharacter를 만들지 않는다.
- [ ] 미선택 상태의 공격/스킬/회피/궁극기 요청은 거부된다.
- [ ] 12슬롯을 채운 뒤 13번째 출전 요청 거부. 기존 참가자의 예약 변경은 가능하다.
- [ ] Roblox place MaxPlayers=12 설정을 확인한다.

## P0-2 대기/카운트다운

- [ ] 1명은 WAITING. BRICKYARD 이동과 구현된 스킬의 연출/이동 연습이 가능하다.
- [ ] 명중/폭발/지속 피해/패링 반격/환경 리셋이 연습 점수·게이지를 증가시키지 않는다.
- [ ] 실제 스폰된 2명부터 5초 COUNTDOWN. 선택했지만 모델 로딩 중인 사람은 준비 인원으로 세지 않는다.
- [ ] 카운트다운 중 퇴장/낙사 시 취소되고, 회복 후 온전한 5초가 다시 시작한다.
- [ ] ACTIVE 진입 시 연습 탄환·폭탄·시전·재장전·콤보·이동 허가가 남지 않는다.
- [ ] 상태 전환으로 기존 ForceField 감시/2초 서버 보호가 중복되거나 연장되지 않는다.

## P0-3 전투/부활

- [ ] 420초가 서버 기준으로 흐른다. 클라이언트 시계를 바꿔도 시작/종료 시각을 결정할 수 없다.
- [ ] 실제 처치의 KO/데스가 1번만 반영되고 환경 사망은 데스만 1 증가한다.
- [ ] 4초 이전 재로드 없음. 로드 지연 시 UI가 살아났다고 단정하지 않는다.
- [ ] 실제 부활 후 보호 2초, 공격 시 보호 해제 등 기존 규칙 유지.
- [ ] 사망 중 선택이 다음 실제 부활에 적용되며 같은 라운드 궁극기 이월 상한 40 유지.
- [ ] 최신 5종의 복합 시전/지연 콜백/소유자 사망 후 설치물 규칙은 별도 전체 회귀.

## P0-4 참가/퇴장/경계

- [ ] ACTIVE 중 선택 후 스폰 완료한 플레이어가 즉시 참가하고, 먼저 발사된 경기 이전 효과는 피해를 주지 않는다.
- [ ] 참가자 1명/0명에서 20초 유예. 사망자는 참가 인원에 남는다.
- [ ] 유예 19.9초의 실제 합류는 취소를 막고, 만료 후 늦게 완료된 로드는 종료된 경기에 편입되지 않는다. 취소되면 RESULTS 없이 WAITING으로 즉시 복귀하고 HUD에는 취소 안내만 나온다.
- [ ] 인원 회복 후 다시 줄면 새로운 20초 유예. 같은 타이머를 재사용하지 않는다.
- [ ] 퇴장자의 오래된 스폰/시전 콜백과 같은 UserId 재접속이 새 상태를 덮어쓰지 않는다.
- [ ] CharacterAdded가 지연/중복될 때 accepted ticket이 다른 모델에 재사용되지 않는다.
- [ ] 엔진 로드가 아직 반환하지 않았다면 경기 전환 후에도 다음 로드 호출을 겹치지 않는다.
- [ ] 로드 실패 5회 후 Heartbeat가 무한 재시도를 만들지 않는다. 명시적 선택 재시도에서도 시간창 상한 유지.
- [ ] 맵 생성 지연/실패, Humanoid/HRP 지연 후 모든 epoch/접속/모델 검증을 다시 수행한다.

## P0-5 종료/다음 경기/UI

- [ ] 경기 만료와 동시에 날아오는 탄환·폭탄·지속 피해가 종료 후 기록을 바꾸지 않는다.
- [ ] RESULTS에서 신규 스킬/회피/장전/궁극기/달리기 시작이 차단된다.
- [ ] 1,1,3 등의 공동 순위가 서버 rank와 UI 모두 일치한다. 동점 이름 정렬을 별도 순위로 오해하지 않는다.
- [ ] 정상 결과 중 퇴장/접속/선택으로 확정 결과가 변하지 않는다. 인원 부족 취소는 결과표와 승리 순위를 표시하지 않는다.
- [ ] 12초 결과 뒤 WAITING 또는 5초 COUNTDOWN으로 복귀하고 다음 경기가 자동 시작한다.
- [ ] 여러 라운드 반복 후 과거 점수/게이지/캐릭터 예약/폭탄/피드백이 잘못 이월되지 않는다.
- [ ] 첫 선택 전에 기존 UI가 Dead 화면을 표시하지 않도록 match.player.state를 연결했다.
- [ ] 이탈 기록으로 결과가 12행을 넘을 때 스크롤/필터 처리와 내 행 강조를 확인한다.
- [ ] MatchChanged 같은 미정 Remote를 임의 추가하지 않고 기존 State/Scoreboard/Feedback으로 표시한다.

실제 Studio 실행 로그·스크린샷·클라이언트 수·테스트 시각을 기록하기 전까지 위 항목을 통과로 표시하지 않는다.
