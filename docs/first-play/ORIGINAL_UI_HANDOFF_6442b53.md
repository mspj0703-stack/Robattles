## 기존 구현 대조

| 항목 | 기존 상태 | 이번 처리 |
|---|---|---|
| PLAY → 선택 → 서버 요청 | 구현됨 | 첫 스냅샷 전 PLAY도 선택 화면으로 이동. 자동 출전 요청 없음 |
| 5종 HP·스킬·패시브 | 구현됨 | 재사용; 카드에 HP·짧은 역할·난이도, 상세에 공식 한 줄 소개 추가 |
| 역할·조작 난이도 | 역할 태그만 존재, 난이도 없음 | SWORD 보통 / PAINTBALL 쉬움 / SUPERBALL 어려움 / TIMEBOMB 보통 / SLINGSHOT 어려움 |
| 카드 탐색과 실제 제출 분리 | 구현됨 | 유지. CTA `선택하고 출전`, 기존 참가자는 다음 리스폰 선택 |
| 승인·스폰 중 중복 입력 방지 | 요청 중만 차단 | 서버 Selected + 아직 미스폰이면 계속 차단; 서버 Failed 시 재시도, 응답 지연 시 연결 대기 |
| WAITING 인원 | 서버 값 표시됨 | 참가자 n/2, 다른 플레이어 대기, 피해·KO·데스·궁극기 충전 없음 안내 추가 |
| COUNTDOWN·ACTIVE·사망/부활/보호 | 구현됨 | 상태 처리와 서버 시각 사용 유지. 연습 안내는 ACTIVE에서 숨김 |
| 사망 중 캐릭터 예약 | 구현됨 | 기존 현재/예약 캐릭터 유지, 다음 리스폰 적용 흐름 유지 |
| 취소와 정상 결과 | UI 구분 구현됨 | 재사용. 취소 배너에 정상 결과 행/승자 표시하지 않음 |
| 공동 순위·재접속 기록 | 서버 스냅샷 표시 구현됨 | 재계산/0 초기화/합산하지 않음 |
| 3D 프리뷰 | 정상 경로만 존재 | 생성 실패 시 스크립트 없는 정적 R6 실루엣으로 대체, 출전 요청 가능 |
| 작은 화면 | UIScale + 상세/조작법 스크롤 구현됨 | 유지. 카드 5개 동시 노출 배치 확장, 상세 소개도 스크롤 포함 |
| 조작법 | 구현됨 | R 재장전을 지원 캐릭터에만 해당한다고 명시 |

난이도는 조작 복잡도 초안이며 성능/승률 등급이 아니다. TIMEBOMB 보통은 명세대로 유지했고 실기 전 임의 변경하지 않았다. 기본 SWORD 미리보기는 실제 서버 선택/캐릭터 스폰이 아니다. PLAY → 현재 프리뷰의 CTA는 2회 동작이고 다른 캐릭터를 탐색하면 카드 클릭이 추가된다. 카드 클릭 자체가 출전하는 동작으로 바꾸지 않았다.

## 변경 파일 및 적용

코드 4개, 기존 테스트 파일에 8개 테스트 추가:

- `src/client/UI/Catalog.luau`: 역할/소개/조작 난이도 표시 데이터.
- `src/client/UI/App.luau`: 카드·CTA·출전 대기·연습 안내·프리뷰 안전 호출.
- `src/client/UI/Preview.luau`: `safeNew` + 생성 실패 시 정적 실루엣.
- `src/client/HudView.luau`: 상단 비전투 안내 라벨.
- `tests_ui/views.spec.luau`: 첫 접속/중복 요청/서버 실패/대기 상태/프리뷰 실패/난이도/지연 회복 검증. 기존 테스트 삭제·수정·완화 없음.

`first-play.patch` 또는 `overlay/`는 **이전 UI 전달본 6442b53 기준의 증분**이다. `apply_ui_overlay.py`의 기본 해시 검사 후 적용하며 다른 담당자 수정이 있으면 중단한다. Main 패치가 새로 필요하지 않다. 이전 UI 전달본의 Main 어댑터를 아직 통합하지 않았다면 이전 인계 절차는 여전히 필요하다.

전체 `reference_snapshot`은 검토/재현용이며 다른 최신 프로젝트 전체에 덮어쓰지 않는다. 검수방이 최신 통합 소스에서 변경 4개 UI 파일만 대조·병합하고 아래 검증을 재실행한다.

## 남은 통합·검증

이전 참고 소스의 MatchFlow에는 취소 시 RESULTS 진입 및 공개 결과 재순위 미반영 문제가 남아 있다. 이번 명세 반영으로 서버 구현이 완료된 것이 아니다. S5-R1 서버 패치를 검수방에서 합친 뒤 즉시 WAITING·재접속 복원·퇴장자 제외 공개 순위를 실기로 확인해야 한다. UI가 서버 phase를 강제로 바꾸거나 클라이언트에서 순위를 보정하지 않는다.

- [ ] 처음 접속해 PLAY → 5카드 비교 → 선택하고 출전. 실제 자동 SWORD 스폰 없음.
- [ ] 선택 연타/서버 승인 후 로딩/응답 지연/Failed 재시도. 실제 중복 출전 없음.
- [ ] WAITING n/2가 실제 출전 인원과 일치, 연습 피해·점수·궁극기 증가 없음.
- [ ] COUNTDOWN 취소/ACTIVE 전환 시 안내가 섞이지 않음.
- [ ] 사망 중 변경은 다음 부활, 4초/2초 보호 서버 값 일치.
- [ ] 정상 결과 12초와 취소 즉시 WAITING·짧은 배너 분리, 서버 공동 순위/재접속 유지.
- [ ] 프리뷰를 사용할 수 없어도 실루엣·선택/출전이 동작.
- [ ] 1920×1080/1280×720/800×600/640×360 및 태블릿 가로: 5카드·HP·난이도·상세 스크롤·CTA 가독성과 클릭 범위 확인.

최종 공개/릴리스 완료로 표시하지 않는다. 새 기획이 오면 본 대조표를 다시 갱신한다.
