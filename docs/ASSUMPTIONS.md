## A62. 캐릭터 로드 경쟁 상태 방지 (CLI 검증 / Studio 미검증)
- LoadCharacterAsync 는 yield 이며 타임아웃이 와도 실행 중인 호출은 취소되지 않는다고 가정한다(Studio 미검증).
- RespawnScheduler: due() 가 호출마다 전역 고유 attemptId 를 발급하고 inFlight 로 표시. 호출이 반환하는 finishCall(id, attemptId, ok, now) 으로만 inFlight 가 풀린다. 타임아웃(10초)은 "slow" 로그만 남기고 새 호출을 시작하지 않는다. 60초(LoadHangSeconds) 무응답이면 hung 으로 기록하고 재시도 중단(호출은 취소하지 않으며, 이후 캐릭터가 오면 onSpawned 로 복구).
- 호출 반환 후 CharacterAdded 가 LoadTimeoutSeconds 안에 없으면 실패 처리(재시도 1초 뒤, MaxLoadAttempts 상한).
- 오래된 attemptId·퇴장한 플레이어의 finishCall 은 무시. Main.server 의 loadingNow 플래그 제거(스케줄러가 겹침 보장).
- CharacterSpawnGate: 같은 모델의 중복 CharacterAdded 무시, yield 중 더 새로운 스폰/퇴장 시 stale 처리(퇴장한 플레이어의 캐릭터는 Destroy), 교체된 모델의 늦은 Died 무시.
- 사망/리스폰 중 완료: 늦게 도착한 캐릭터도 "캐릭터 존재" 사실이므로 재시도 예약을 취소한다.

## A68. 캐릭터별 최대 체력 구조 + PAINTBALL 확정/임시 수치 (Phase 2 PAINTBALL, CLI 검증 / Studio 미검증)
**구조(확정 수치)**: 캐릭터 데이터의 `maxHealth` 가 최대 체력이다(SWORD 110 / PAINTBALL 95 / SUPERBALL 100 / TIMEBOMB 105 / SLINGSHOT 100). DamageService 는 `register(id, maxHealth)`·`setMaxHealth(id, max, refill)`·`getMaxHealth(id)` 를 제공하고, 컨트롤러는 addPlayer 때 등록하고 **부활 시(캐릭터 변경 반영 후)** 새 최대 체력으로 가득 채운다. 데이터에 없으면 Config.Combat.MaxHealth(100)를 쓴다. HUD 스냅샷의 `health.max`와 서버의 Humanoid 표시 체력도 같은 값을 쓴다. 기존 테스트는 "100 HP 기준 받은 피해" 단언을 유지하려고 `Helpers.hp(core,id)`(100 기준 환산)를 쓰며, 캐릭터별 HP 자체는 Paintball.spec "캐릭터별 최대 체력"이 따로 검증한다.
**PAINTBALL 확정**: HP 95 · LMB Paint Shot 7 / 초당 3발 / 탄창 16 / 재장전 1.2초 / 서버 투사체 · RMB Paint Burst 독립 투사체 5개×5(같은 대상 다중 적중, 최대 25) / 탄 3 소모 / 후딜 약 1초 · Skill 1 Color Bomb 광역 24 / 쿨 9 · Skill 2 Piercing Shot 대상당 30 / 최대 3명 / 쿨 12 / 이중 적중 없음 · Skill 3 Paint Slide 12 스터드 / 쿨 7 / 무적 없음 / 슬라이드 중 LMB·RMB 가능 / Movement Permit · Ultimate Color Break 전조 0.8초 + 빔 약 2.5초 / 0.25초마다 6 / 대상당 최대 60 / 시전 중 조준 가능 · Passive Color Reload.

## A69. Color Reload 세부 해석 (임시 해석, 사양 문구에 대한 보수적 해석)
- 유효 적중 = DamageService 가 실제로 피해를 적용한 Paint Burst 펠릿 / Piercing Shot 관통 대상 / Color Bomb 폭발 대상(시전자 제외). 부활 보호·회피 무적·패링·사망 대상은 제외. LMB·Paint Slide·궁극기는 발동하지 않는다.
- "재장전 중이면 재장전을 즉시 취소하고 탄약을 회복": 재장전을 취소(`reloadingUntil=0`)하고 **현재 탄 + 3**(탄창 한도)로 만든다. 탄창을 가득 채우지 않는다. 재장전은 시각 비교 방식이라 취소 후 옛 완료 시각에 탄이 덮어써지지 않는다(테스트).
- 회복할 것이 없으면(탄창 가득 + 재장전 아님) 발동·5초 잠금 모두 일어나지 않는다(잠금 낭비 방지, 사양에 명시 없음 → 임시).
- 한 번의 Paint Burst 에서 여러 펠릿이 맞아도 첫 유효 적중에서만 발동하고 이후는 5초 잠금.
- 투사체는 발사한 생애(부활·캐릭터 변경·퇴장 시 증가)를 기억한다: 이전 생애 투사체의 적중은 패시브를 발동하지 않는다(투사체 자체는 수명 동안 유지·피해는 적용).

## A70. Aim 리모트와 Color Break 해석
- 새 클라→서버 리모트 `Aim`(aimOrigin·aimDirection·clientTime만): RemoteGate 검증(스키마·빈도·사망·시각·원점) 통과 후 컨트롤러가 최근 조준을 저장하고, 해당 캐릭터 모듈이 지속 시전 중일 때만 반영(그 외는 거부 `no_aim_use`). 클라이언트는 빔 시전 중에만 Config.Hud.AimSyncHz(15Hz, 임시)로 전송.
- 빔 판정은 전부 서버: 틱 시각 = 시작 + 0.8 + k×0.25 (k=1..10), 서버 시각에 맞춰 처리(큰 dt 에도 10틱 고정). 눈 높이에서 현재 조준 방향으로 길이 70의 선분, 벽(월드 cast)에서 끊고, 대상 구(반지름 + 빔 반지름 1.2)와의 교차로 판정. 대상별 누적 피해 60 상한. 같은 틱의 중복 적용 없음.
- 시전 중 사망 시 이후 틱 없음(UltimateService 사망 처리 + 모듈 reset). 기절 등 행동 불가는 빔을 끊지 않는다(임시). 자발적 취소 불가(기존 규칙). 시전 중 이동속도 변화 없음(사양 없음 → 임시).
- 서버는 클라이언트의 조준 회전 속도를 제한하지 않는다(임시, Studio 감각 확인 후 필요하면 추가).

## A71. Paint Slide · Paint Burst · 자동 연사 해석
- Paint Slide 방향 = 조준 방향의 수평 성분(이동 입력 방향이 아님). 서버가 벽 cast 로 거리를 줄이고(Config.MoveCheck.WallSkin), 남은 거리가 1 미만이면 `blocked` 로 거부(쿨타임 불변). 이동 허가(PaintSlide: 상한 속도 45·지속 1.5초·재발급 1초)를 서버가 발급하지 못하면 `movement_denied:*` 로 거부. 판정/피해 필드가 없는 `kind="Movement"` 라 부활 보호를 해제하지 않는다(ActionPolicy). 클라이언트는 서버 이벤트(CharSkill + dash{speed,duration,permit})만 따르고 해당 허가 종류의 상한으로 속도를 제한(MovementModel.dashVelocity permitKind).
- 자동 연사(LMB 홀드)는 클라이언트가 fireInterval 마다 Attack 을 반복 요청할 뿐이고, 간격·탄약은 서버가 매 요청 검증한다.
- Paint Burst 는 탄이 3 미만이면 거부(자동 재장전 시작 안 함), 재장전 중 거부, 투사체 상한이면 통째로 거부.
- 연출 이벤트는 공통 `CharSkill{cue,...}` 형식(서버가 큐 이름 지정, 클라이언트는 카탈로그에 있는 큐만 재생). 이후 캐릭터도 같은 형식을 쓴다.

## A72. SUPERBALL 임시 수치·해석 (Phase 2)
- 확정(사양): HP 100, LMB 일반 18(지형 튕김 2회·수명 약 5초)/충전 약 1초 28(3회·약 6초), Bounce Dash 10스터드·쿨 7·무적 없음, 스킬1 3발×12·쿨 9, 스킬2 5발×7·쿨 12, 스킬3 귀환 볼당 12·쿨 8, 궁극기 공전 10개·최대 12초·접촉 8·발사 12, 볼 총량 12, Trick Master 0.5초·재발동 1초.
- 임시: 볼 속도(75/100)·중력(28)·반경·반발계수 0.8·던지기 간격 0.6초·충전 중 이동 80%·충전 최대 유지 4초(초과 시 취소)·산탄/연사 각도(Rapid ±5°, Scatter 0/±9/±18°, 모두 즉시 발사)·귀환 속도 70·공전 반지름 4/주기 1.6초/높이 1.5·접촉 간격(볼·대상 0.6초, 대상 전체 0.2초)·궁극기 발사 속도 90·발사 간격 0.4초.
- 충전 판정: 쥔 시간 ≥ 1.0초면 충전 볼, 그 미만은 일반 볼(중간 충전 단계 없음). 시간은 서버가 Press/Release 도착 시각으로 잰다(클라이언트 시각 무시). Release 없음은 서버가 정리, 4초 초과 Release 는 `charge_expired` 로 취소(쿨타임·보호 불변). 보호 해제는 실제 던지는 순간(Press 는 비공격).
- `phase` 생략 Attack = 즉시 일반 던지기(호환). 충전형 주무기는 Attack 리모트에 optional `phase`(Press/Release)를 쓴다.
- 비행 "단계": 지형에서 튕기거나 적 몸에서 튕겨 나갈 때마다 증가. 같은 단계에서는 같은 대상을 1번만 맞히고, 다른 단계에서는 다시 맞힐 수 있다(attackId = 볼#단계). 적 몸에서 튕기는 것은 지형 튕김 횟수를 쓰지 않는다. 회피 무적·부활 보호·사망 대상은 피해 없이 통과(튕기지 않음). 패링에 막히면 볼 소멸.

## A73. SUPERBALL 패시브·볼 총량·궁극기 해석
- Trick Master 유효 적중 = 지형에서 1회 이상 튕긴 볼이 적에게 실제 피해를 줌(귀환 적중 포함, 궁극기 접촉 제외). 소유자가 살아 있고 SUPERBALL 이며 같은 생애일 때만. 감소 대상 = 스킬 1~3 중 남은 쿨타임이 가장 긴 것 1개(동률은 낮은 번호), 감소량 = min(0.5, 남은 시간). 줄일 쿨타임이 없으면 발동도 1초 잠금도 일어나지 않는다. 궁극기·대시(RMB)는 대상 아님.
- 볼 총량 12: 일반 볼 생성 시 빈 슬롯이 부족하면 소유자의 가장 오래된 일반 볼부터 제거. 궁극기 볼(공전 + 발사된 것)은 일반 볼 생성으로 밀려나지 않는다 → 궁극기 중 일반 슬롯은 12−궁극기 볼 수. 다발 스킬은 빈 슬롯 수만큼만 생성(나머지는 생략).
- 궁극기 발동: 총량 12 를 지키도록 가장 오래된 일반 볼부터 제거 후 공전 볼 10개 생성. LMB = 조준 방향 앞쪽에 가장 가까운 공전 볼 1개를 현재 위치에서 조준 방향으로 발사(12, 튕김 1회·수명 3초). 종료·사망·캐릭터 변경 시 궁극기 볼 전부 제거. 충전 중 궁극기를 쓰면 충전 취소. 이미 발동 중이면 거부(게이지 불변).
- 공전 접촉 피해는 막을 수 없는(blockable=false) 직접 접촉. 대상 전체 간격 0.2초·볼-대상 간격 0.6초는 임시(한 번에 80 피해 방지 목적).

## A74. Recall(스킬 3) 해석
- 대상 = 소유자의 "날고 있는 일반 볼"(궁극기 볼 제외). 대상이 없으면 `nothing_to_recall` 로 거부(쿨타임 불변). 귀환 볼은 소유자 눈높이를 향해 직선 비행(적 유도 없음), 경로 스윕으로 적을 맞히며 볼당 대상당 1회 12 피해(귀환 attackId 는 비행 단계와 별개). 서로 다른 볼의 피해는 합산(인위적 상한 없음).
- 지형에 막히면 우회하지 않고 소멸(`ReturnBlocked`). 소유자 3스터드 이내 도착하면 회수(`Recalled`). 귀환 3초 초과 시 소멸.

## A75. 클라이언트 볼 표현
- 서버가 BallSpawn/BallBounce/BallMode/BallEnd 이벤트로 위치·속도·모드를 알리고, 클라이언트는 그 사이를 보간만 한다(판정은 서버). 모든 BallSpawn 은 BallEnd 와 짝을 이룬다(테스트).

## A76. 폭발 감쇠 프로필 (TIMEBOMB 확정 사양) — 기존 A07 은 그대로 유지
- 확정: 같은 공격자의 폭발이 같은 대상에 0.3초 안에 반복되면 100% → 60% → 30%(이후 30% 유지). **TIMEBOMB 폭발(`explosionProfile = "Timebomb"`)에만** 적용한다. 다른 캐릭터의 폭발(PAINTBALL Color Bomb 등)은 기존 A07(0.5배·최소 0.25·1.5초)을 그대로 쓰고, 빔·직접·투사체·근접 다단 히트(Color Break, Blade Storm 등)는 `kind="Explosion"` 이 아니라서 어느 감쇠도 받지 않는다.
- 카운터는 공격자 × 프로필 × 대상별로 독립이다. 다른 플레이어의 폭발이나 다른 프로필과 공유하지 않는다. 각 폭발은 별도 attackId 의 유효 적중이어야 센다(피해가 실제로 적용된 경우에만 기록).
- 새 이동 허가 `BlastGuard`(Blast Guard 자기 반동): maxSpeed 60·maxUp 20·maxDuration 0.5·재발급 1초(임시).
- 폭발 반경/위치: 자기 체력 피해는 항상 면제. 벽·지형 차폐는 폭탄 중심 → 대상 시선(lineOfSight) 검사. 거리 감쇠: 일반 폭탄 없음(평탄), Big Bang 중심 70 → 가장자리 35 선형(표면 거리 기준).

## A77. TIMEBOMB 임시 수치·해석
- 확정은 Data/Characters.TIMEBOMB 머리 주석 참고. 임시: 폭발 반경(Timed 6·Cluster 6·자탄 4·Blast Guard 6), 투척 속도 45/40·중력 35, 자탄 개수 외 각도(pitch 50°)·속도 14·폭발 간격 0.35초(감쇠 창 0.3초 밖이라 자탄마다 100%), Blast Guard 반동 6스터드(0.25초)·넉백 40, Blast Jump 방향(조준 방향, 위쪽 성분 최소 0.5)·지속 0.5초, 설치 수명 30초(만료 시 폭발 없이 소멸), 던지기 간격 0.3초, 누르기 상한 10초, Big Bang 투척 속도 50(Blast Jump 3초 안 공중이면 75), 비행 한도 6초, 소유자당 동시 폭탄 상한 24.
- Remote Bomb 입력: Press = 누르기 시작(비공격, 보호 유지), Release 시 누른 시간 < 0.4초면 설치(충전 1·설치 최대 2·던지기 간격 확인), ≥ 0.4초면 전체 기폭(설치물이 없으면 `nothing_to_detonate` 거부, 충전·쿨타임 소모 없음). 충전 복구는 사용한 충전마다 독립적으로 11초 뒤. 중복·지연 Release 는 `not_holding`, 10초 넘은 누르기는 `hold_expired`.
- Chain Reaction: 자기 폭탄만, 반경 7스터드(폭탄 중심 기준), 최초 폭발 = 1단계 최대 3단계, 같은 폭탄 중복 기폭 없음, 단계 순(FIFO)·생성 순번으로 결정적. **자탄(Mini)과 Big Bang 은 연쇄 대상에서 제외**(자탄은 차례로 터지도록, Big Bang 은 3초 타이머 보호). 원격 전체 기폭과 타이머 만료는 각각 1단계 시작. Blast Guard·Blast Jump 의 폭발도 근처 자기 폭탄을 2단계로 연쇄 기폭한다(이 폭발 자체가 1단계).
- Blast Jump 는 피해 없는 이동기(부활 보호 유지)로 처리한다(사양에 피해 언급 없음). 허가 거부·위가 막힌 경우 쿨타임 불변. Blast Guard 는 뒤가 벽이면 반동만 생략하고 폭발은 그대로 한다.
- 폭탄은 플레이어를 통과한다(접촉 기폭 없음, 지형만 정지). 사망·리스폰·캐릭터 변경 시 설치물(원격 폭탄)과 누르기 상태를 정리하고, 이미 던진 Timed/Cluster/Big Bang 은 남아서 소유자 이름으로 폭발한다. 퇴장 시 전부 제거(폭발 없음).

## A78. 클라이언트 폭탄 표현·수직 이동
- 서버가 BombSpawn/BombLand/BombExplode/BombEnd 로 위치·시각을 알리고 클라이언트는 보간만 한다(모든 BombSpawn 은 종료 이벤트와 짝, 테스트).
- Blast Jump 의 수직 성분은 dash.up 으로 전달하며 클라이언트는 허가 종류(BlastJump)의 maxUp 이하로만 적용한다(MovementModel.dashVelocity 의 8번째 인자). 허가 종류를 모르면 수직 이동 없음.
