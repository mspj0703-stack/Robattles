# Roblox Studio 실기동 검증 절차 (미실행)

아래 항목은 Roblox API(Raycast/Spherecast, RemoteEvent, Humanoid, Heartbeat)에 의존해 Luau CLI로 검증할 수 없다.
**현재 전부 미검증이다.** Studio에서 실행하고 결과를 기록하기 전에는 PASS로 보고하지 않는다.

## 준비
1. `rojo build -o RoBattles.rbxlx` 또는 `rojo serve` + Studio 플러그인 연결
2. 베이스플레이트 + 벽 파트 몇 개(Anchored, CanCollide=true) 배치
3. Test → Clients and Servers: Start (서버 1 + 클라이언트 2~3)

## 4단계 추가 항목 (모두 미검증 — Studio 에서 실행하기 전에는 PASS 로 보고하지 않는다)
통합 프로젝트 준비: `rojo build integrated.project.json -o RoBattles.rbxlx` (또는 `rojo serve integrated.project.json`). 기본 Baseplate 의 SpawnLocation 은 두어도 되고 지워도 된다(두는 편이 "기본 스폰에 나타나지 않는다"를 확인하기 좋다).
로그 확인: 출력창에서 `[RoBattles]`, `[BRICKYARD]` 접두어를 확인하고 빨간 오류/노란 경고(`[RoBattles][Move]`, `[RoBattles][Spawn]`, `[RoBattles][Respawn]`)를 기록한다. 서버/클라이언트 로그는 Test 탭에서 각각 확인.
시간 확인: 서버 Heartbeat 시각 기준 사망→부활 4.0초, 보호 2.0초(±프레임/네트워크 지연 허용 0.2초). 화면 녹화 후 프레임 단위로 확인하면 정확하다.
