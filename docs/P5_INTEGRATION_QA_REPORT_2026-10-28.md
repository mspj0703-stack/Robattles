### 왜 전체 테스트 9개가 실패했는가

QA4~P1/P2/P3/P4 과정에서 단계별로 `App.luau`, `Main.client.luau`, `EffectPlayer.luau` 등 표시 코드가 정상적으로 변경되었다. 예전 단계의 테스트 9개는 **그 후속 수정 자체를 금지하거나 예전 파일과 완전히 동일하다고 가정**하여 실패했다. 이번 P5에서는 구형 테스트를 수정/삭제하지 않았으며, 어떤 테스트를 제외했는지 `tools/run_p5_offline.py`에 이름으로 명시했다. 이 9개를 제외했다고 Roblox Studio 동작이 검증되는 것은 아니다.

## 2. P5에서 추가한 검사

- `tests_py/test_p5_cumulative_contract.py`의 7개 정적 계약 검사.
- QA4 기준으로 서버, 맵, 캐릭터 데이터, 애니메이션, 입력과 피해 관련 미허용 파일의 소스 변경이 없는지 확인.
- P3의 피해 숫자와 KO 알림이 서버 이벤트를 사용하는 소스 경로인지 확인.
- P1~P2의 VFX 대체 경로 및 사운드 폴백·11개 cue 믹스가 남아 있는지 확인.
- P4-B의 가로/세로 프로필, 레이아웃 복구 코드가 남아 있는지 확인.
- `tools/run_p5_offline.py`로 검사를 재실행할 수 있도록 정리.

이 검사는 모두 소스 수준 계약 검사이며, 가시성·실제 물리·사운드·FPS 등의 런타임 동작을 판정하지 않는다.

## 3. 여전히 남은 확인 사항

1. **P0: Luau CLI 컴파일·분석** — 소스 문법·모듈 실행 오류 및 기존 Luau 회귀 테스트.
2. **P0: Roblox Studio/실기** — 스폰·사망·부활·경기 시작/종료, 5캐릭터 스킬 입력, 애니메이션·모델·VFX·SFX·HUD 연계.
3. **P1: 모바일/작은 화면** — 글자 가림, 화면 회전, safe area, 설정 UI. P4-B는 터치 전투 입력을 추가한 버전이 아니다.
4. **P1: 신규 SFX 11종** — 프로토타입 WAV만 존재; Roblox 음원 업로드·SoundId 지정·권한·재생 테스트 필요.
5. **P1: 12인 FPS/네트워크 성능** — VFX/음성 중복, 이펙트 클린업, 장시간 경기, UI 유지 테스트 필요.

## 4. 안전한 적용·검증 방법

- P4-B 원본 ZIP과 P5 Git 번들을 보관하고, GitHub `main`에 직접 덮어쓰지 않는다.
- P5의 커밋은 **QA 테스트/보고서/실행 스크립트만** 추가한다. 기존 전투/애니메이션 소스는 그대로다.
- 로컬 Git 번들 복원 후 `python tools/run_p5_offline.py` 실행; 과거 범위 검사 9개를 제외한 결과 및 미실행 항목 확인.
- Roblox Studio 또는 적절한 외부 테스트 환경 확보 후 실기 체크리스트를 수행하여 릴리스 여부 결정.

**결론:** P5 오프라인 코드/계약 검수는 통과했다. 하지만 **실제 Roblox 게임 완성, Luau 컴파일 통과, 공식 릴리스 준비 완료를 의미하지 않는다.** GitHub 푸시/배포 없음.
